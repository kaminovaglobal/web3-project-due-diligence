# Research Toolkit

The source material identifies these research categories and example tools.

| Category | Examples | Use |
|---|---|---|
| Blockchain explorers | Etherscan, BscScan, BaseScan, Arbiscan and chain-specific explorers | Contracts, holders, transactions, permissions |
| DeFi analytics | DefiLlama | TVL, protocols, chains, yields and ecosystem activity |
| Market data | CoinGecko, CoinMarketCap | Market cap, supply, listings and market data |
| Developer research | GitHub | Repositories, contributors, commits, issues and releases |
| DEX analytics | Chain/DEX-specific analytics tools | Liquidity, pools, volume and trading activity |
| Security research | Audit reports, explorers, contract-analysis tools | Permissions, vulnerabilities and security evidence |
| Official sources | Project website, documentation and verified social accounts | Claims, announcements and primary evidence |

## Evidence Collection Rule

Use primary and independently verifiable evidence where possible. Record the exact source and what it proves rather than copying a project's claim without verification.

## Suggested Evidence Log

For each important claim, capture:

- Claim
- Source URL or transaction/contract reference
- Date checked
- What the source actually demonstrates
- Contradictory evidence, if any
- Remaining uncertainty
