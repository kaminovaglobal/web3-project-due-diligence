# Web3 Project Due Diligence Checklist

## 7-P Check

- [ ] **Problem** — What problem is being solved?
- [ ] **Product** — Is there a real product?
- [ ] **People** — Who built it and what is their track record?
- [ ] **Protocol** — How does it work?
- [ ] **Protection** — What can go wrong and who has privileged control?
- [ ] **Profit** — How do tokenomics and value capture work?
- [ ] **Proof** — What independent evidence supports the claims?

## Contract & Security

- [ ] Contract verified
- [ ] Ownership/admin identified
- [ ] Mint permissions checked
- [ ] Pause permissions checked
- [ ] Blacklist permissions checked
- [ ] Fee controls checked
- [ ] Sell restrictions checked
- [ ] Upgradeability checked
- [ ] Proxy/upgrade authority identified
- [ ] Privileged functions reviewed
- [ ] Audit report obtained
- [ ] Correct contract/version confirmed
- [ ] Findings and severity reviewed
- [ ] Critical/high findings remediation checked
- [ ] Deployed code matches reviewed code

## Tokenomics

- [ ] Total supply
- [ ] Circulating supply
- [ ] Market capitalization
- [ ] FDV
- [ ] Team allocation
- [ ] Investor allocation
- [ ] Treasury
- [ ] Community/ecosystem allocation
- [ ] Liquidity
- [ ] Vesting/unlocks
- [ ] Inflation/emissions
- [ ] Token utility
- [ ] Holder concentration

## Liquidity & On-Chain

- [ ] Liquidity size
- [ ] Liquidity location
- [ ] LP token control
- [ ] Lock duration, if applicable
- [ ] Ability to remove liquidity
- [ ] Liquidity concentration
- [ ] Transactions
- [ ] Token holders
- [ ] Treasury wallets
- [ ] Token transfers
- [ ] Contract ownership
- [ ] Whale activity
- [ ] Deployer history
- [ ] Protocol usage

## Team, Community & Partnerships

- [ ] Team identities/track record checked
- [ ] LinkedIn/GitHub checked
- [ ] Previous projects checked
- [ ] Community engagement quality checked
- [ ] Hard questions/criticism reviewed
- [ ] Past promises compared with delivery
- [ ] Partnership claims independently verified
- [ ] Developer activity checked

## Human Attack Surface

- [ ] FOMO pressure identified
- [ ] Authority bias considered
- [ ] Social proof separated from evidence
- [ ] Urgency tactics considered
- [ ] Confirmation bias checked
- [ ] Sunk-cost thinking avoided

## Final Questions

- [ ] What evidence supports the key claims?
- [ ] What remains unresolved?
- [ ] What could go wrong?
- [ ] What happens if everything goes wrong?
- [ ] Do I still understand why I am joining?
