# The 10-Minute Web3 Project Test

A rapid first-pass investigation before deeper research.

1. [ ] What does it do?
2. [ ] Who built it?
3. [ ] Check the website and documentation.
4. [ ] Check tokenomics.
5. [ ] Check the contract and permissions.
6. [ ] Check holders and concentration.
7. [ ] Check liquidity.
8. [ ] Check security/audit claims.
9. [ ] Check GitHub and/or on-chain activity.
10. [ ] Search for credible criticism and unresolved complaints.

> **After these 10 minutes, do you still understand why you're joining?**

The purpose of this test is to identify what deserves deeper investigation. It is not a substitute for full due diligence.
