# Contributing

Contributions should improve the clarity, repeatability and evidence quality of Web3 project due diligence.

## Guidelines

- Keep changes evidence-focused.
- Preserve the 7-P terminology unless a change is explicitly documented.
- Avoid presenting uncertain claims as facts.
- Add sources when introducing project-specific claims.
- Keep checklists practical and auditable.
- Do not turn the framework into financial advice or a guarantee of project safety.

## Pull Requests

Describe:

1. What changed.
2. Why it improves the framework.
3. Any new sources or evidence.
4. Any limitations or unresolved questions.
