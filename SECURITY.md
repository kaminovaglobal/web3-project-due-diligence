# Security Policy

This repository contains a research and due-diligence methodology. It is not a guarantee that a project, smart contract, token or opportunity is safe.

## Reporting Security Issues in This Repository

If you discover a security issue in the repository itself, please avoid publishing sensitive exploit details in a public issue before a maintainer has had an opportunity to review them.

Provide:

- A concise description.
- Affected file/component.
- Reproduction steps where appropriate.
- Potential impact.
- Suggested remediation, if known.

## Research Safety

When using the framework on real projects:

- Never share seed phrases or private keys.
- Treat unknown wallet connections, token approvals and signatures cautiously.
- Do not install suspicious software or execute unknown scripts.
- Verify contract addresses and sources independently.
