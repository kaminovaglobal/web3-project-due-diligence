# Web3 Project Due Diligence Framework

An evidence-first framework for researching a Web3 project before committing your **money, wallet, time, reputation, or professional skills**.

> **Core message:** Don't trust the hype. Verify the evidence.

## The 7-P Framework

| P | Question | What to verify |
|---|---|---|
| **Problem** | What problem are they solving? | Real users, real need, why blockchain matters |
| **Product** | What have they actually built? | Live product, demos, documentation, usage |
| **People** | Who is behind it? | Identity, track record, previous work |
| **Protocol** | How does it work? | Architecture, contracts, dependencies, governance |
| **Protection** | How secure is it? | Audits, permissions, ownership, attack surface |
| **Profit** | How does the economics work? | Token utility, supply, FDV, revenue, incentives |
| **Proof** | What evidence supports their claims? | On-chain data, GitHub, official announcements |

## Guiding Principles

1. Start with the project, not the token price.
2. Verify claims instead of trusting marketing.
3. Cross-check information across independent sources.
4. Treat audits as evidence about reviewed technical scope, not as guarantees.
5. Distinguish followers from users and partnership logos from verified partnerships.
6. Investigate privileged contract controls and liquidity ownership.
7. Record evidence and unresolved questions before making a commitment.
8. Apply the framework to investors, ambassadors, contributors and job seekers—not only token buyers.

## Important Note

This repository is a due-diligence methodology, not a guarantee that a project is safe or legitimate. The source material explicitly emphasizes that no project can be guaranteed safe and that users should evaluate whether the risk is acceptable for them.
